# Ars Nouveau GTO Edition

本项目是为 [GregTech Odyssey](https://github.com/GregTech-Odyssey) 整合包专门维护的新生魔艺（Ars Nouveau）版本，基于原版 1.20.1 Forge 分支，针对整合包的玩法与运行环境做了相应的适配与调整。

新生魔艺的原作者为 Bailey Hollingsworth 及各位贡献者，原项目地址：<https://github.com/baileyholl/Ars-Nouveau>，官方 Wiki：<https://www.arsnouveau.wiki/>。本版本的改动均由 GregTech Odyssey 团队维护，并非原作者发布的版本；如在使用中遇到问题，烦请反馈至 [GregTech Odyssey 整合包仓库](https://github.com/GregTech-Odyssey/GregTech-Odyssey/issues)，以免给原项目带来不便。

本版本与原版在游戏设计上的差异，详见 [GTO_CHANGES.md](GTO_CHANGES.md)。
